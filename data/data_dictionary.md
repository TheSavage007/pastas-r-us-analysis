# Data Dictionary

`pastas_r_us_locations.csv` has one row per restaurant location (74 rows).

| Column | Type | Description |
|---|---|---|
| location_id | integer | Location number |
| sqft | integer | Restaurant square footage |
| avg_spend | float | Average spending per person ($) |
| sales_growth_pct | float | Sales growth over the previous year (%) |
| loyalty_pct | float | Loyalty card purchases as a share of net sales (%) |
| sales_per_sqft | float | Annual sales per square foot ($) |
| median_income | integer | Median household income within 3 miles ($) |
| median_age | float | Median age within 3 miles (years) |
| pct_bachelors | float | Share of residents within 3 miles with a bachelor's degree (%) |
| annual_sales_k | float | Annual sales in thousands of dollars (target variable) |
